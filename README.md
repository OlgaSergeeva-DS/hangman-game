# Игра «Виселица» (Hangman)

Консольная игра на Python в стиле «Поля чудес» с классической
ASCII-виселицей. Игрок угадывает слово по буквам, а количество
попыток ограничено.

---

## Правила игры

1. **Компьютер загадывает слово** из файла `words.txt`.
2. **Игрок вводит буквы по одной**, пытаясь угадать слово.
3. **При каждой попытке:**
   - Если буква **есть** в слове — она открывается на своём месте.
   - Если буквы **нет** — сгорает одна попытка, и дорисовывается
     часть виселицы.
4. **Победа:** игрок угадал все буквы слова **до того**, как
   закончились попытки.
5. **Поражение:** попытки закончились, а слово не угадано —
   виселица дорисована полностью.

---

## Управление

| Действие | Как сделать |
|----------|-------------|
| Ввести букву | Введите одну букву и нажмите **Enter** |
| Выйти из игры | Введите `exit` |
| Сыграть снова | После игры ответьте `да` |
| Выйти после игры | Ответьте `нет` |

**Пример хода:**

```
Введите букву (или 'exit' для выхода): п
Буква 'П' есть в слове!
```

---

## Особенности игры

- **Слова загружаются из файла** `words.txt` (по одному слову на строку).
- **Случайный выбор** слова в каждой новой игре.
- **Валидация ввода:** принимаются только буквы, без цифр и символов.
- **Защита от повторов:** одну и ту же букву нельзя ввести дважды.
- **Цветная визуализация:** угаданные буквы — на белом фоне,
  неугаданные — на синем.
- **ASCII-виселица** появляется по мере ошибок.

## Как запустить

### 1. Установите зависимости

```bash
pip install colorama
```

### 2. Создайте файл `words.txt`

Поместите в него слова (по одному на строку):

```
питон
программирование
виселица
алгоритм
функция
переменная
цикл
условие
массив
строка
```

### 3. Запустите игру

```bash
python hangman.py
```

## Возможные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `FileNotFoundError` | Нет файла `words.txt` | Создайте файл со словами |
| `ImportError: colorama` | Не установлена библиотека | `pip install colorama` |
| `ValueError: не содержит слов` | Файл `words.txt` пуст | Добавьте слова в файл |
